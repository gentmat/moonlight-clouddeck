# CloudDeck Integration

This is a shared library for CloudDeck integration that can be used by multiple Moonlight forks.

## Features

- Web automation for CloudDeck portal login
- Cross-platform JavaScript parsing for form interaction
- Credential management and storage
- Integration with Moonlight Qt GUI

## Structure

- `src/` - Core integration code
- `gui/` - GUI components for credential input
- `web/` - Web automation and portal interaction
- `utils/` - Utility functions and helpers

## Usage

This library is designed to be included as a submodule in Moonlight forks.
